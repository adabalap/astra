# Astra
Meaning: Weapon/tool of power.

> A personal arsenal of Unix tools, scripts, automations, and engineering utilities.

"Astra" (अस्त्र / అస్త్ర) means *weapon* or *instrument of power*. In the Unix spirit, each tool in this repository is designed to do one thing well and solve a specific problem.

Over the years, engineers accumulate countless shell scripts, Python utilities, helpers, diagnostics, automations, and small command-line tools. Astra is my collection of those practical artifacts, hardened through real-world use.

---

## Philosophy

Astra follows classic Unix principles:

- Small tools
- Simple interfaces
- Text-first workflows
- Automation over repetition
- Reusability over reinvention
- Pragmatism over complexity

If a task needs to be performed more than once, it probably deserves a tool.
